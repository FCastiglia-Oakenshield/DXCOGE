# VDOX - Schema Export

Istanza SQL Server: SVRSELCO21\XSEL  
Database: VDOX  
Export: schema-only, senza dati cliente

## Contenuto

- `schema/VDOX_schema_only.sql`: script schema-only del database.
- `metadata/VDOX_objects-inventory.csv`: inventario oggetti.
- `metadata/VDOX_tables-columns.csv`: tabelle e colonne.
- `metadata/VDOX_foreign-keys.csv`: foreign key rilevate.
- `metadata/VDOX_indexes.csv`: indici.
- `metadata/VDOX_triggers.csv`: trigger rilevati.
- `metadata/VDOX_routines.csv`: stored procedure e funzioni.
- `notes/VDOX_export-notes.md`: note operative.
- `notes/VDOX_validation-summary.md`: riepilogo controlli.
