# DCDC - Schema Export

Istanza SQL Server: SVRSELCO21\XSEL  
Database: DCDC  
Export: schema-only, senza dati cliente

## Contenuto

- `schema/DCDC_schema_only.sql`: script schema-only del database.
- `metadata/DCDC_objects-inventory.csv`: inventario oggetti.
- `metadata/DCDC_tables-columns.csv`: tabelle e colonne.
- `metadata/DCDC_foreign-keys.csv`: foreign key rilevate.
- `metadata/DCDC_indexes.csv`: indici.
- `metadata/DCDC_triggers.csv`: trigger rilevati.
- `metadata/DCDC_routines.csv`: stored procedure e funzioni.
- `notes/DCDC_export-notes.md`: note operative.
- `notes/DCDC_validation-summary.md`: riepilogo controlli.
