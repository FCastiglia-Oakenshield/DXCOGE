# COGE - Schema Export

Istanza SQL Server: SVRSELCO21\XSEL  
Database: COGE  
Export: schema-only, senza dati cliente

## Contenuto

- `schema/COGE_schema_only.sql`: script schema-only del database.
- `metadata/COGE_objects-inventory.csv`: inventario oggetti.
- `metadata/COGE_tables-columns.csv`: tabelle e colonne.
- `metadata/COGE_foreign-keys.csv`: foreign key rilevate.
- `metadata/COGE_indexes.csv`: indici.
- `metadata/COGE_triggers.csv`: trigger rilevati.
- `metadata/COGE_routines.csv`: stored procedure e funzioni.
- `notes/COGE_export-notes.md`: note operative.
- `notes/COGE_validation-summary.md`: riepilogo controlli.
